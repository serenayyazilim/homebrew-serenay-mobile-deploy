# homebrew-serenay-mobile-deploy

Homebrew tap for [Serenay Mobile Deploy](https://github.com/serenayyazilim/serenay-mobile-deploy).

## Install

```sh
brew tap serenayyazilim/serenay-mobile-deploy
brew install --cask serenay-mobile-deploy
```

Currently Apple Silicon (arm64) only, matching the app's release assets.
